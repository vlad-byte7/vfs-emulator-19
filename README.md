# VFS — эмулятор командной строки

Учебный проект по варианту №19. Программа имитирует интерфейс
командной строки UNIX-подобной операционной системы.

## Текущий этап: 1. REPL

REPL — это цикл «прочитать команду → выполнить → показать результат».
Сейчас приложение содержит графическое окно, парсер аргументов,
заглушки команд `ls` и `cd`, команду завершения `exit` и обработку ошибок.

### Команды

| Команда | Поведение на этапе 1 |
| --- | --- |
| `ls` | Показывает имя команды и список аргументов |
| `cd` | Показывает имя команды и список аргументов |
| `exit` | Закрывает окно эмулятора |

**Важно:** команды `ls` и `cd` пока не работают с файлами — это
требование первого этапа. Настройки пути к VFS и стартового скрипта
появятся на втором этапе.

## Запуск

Нужен Python 3.10 или новее с модулем Tkinter (обычно входит в
установку Python для Windows).

1. Откройте папку `vfs-emulator` в VS Code.
2. Откройте терминал: **Terminal → New Terminal**.
3. Выполните команду:

   ```bash
   python -m src.main
   ```

В Windows можно также запустить `run.bat` двойным щелчком.

## Запуск тестов

В терминале VS Code из корня проекта:

```bash
python -m unittest discover -s tests -v
```

## Примеры

```text
vfs:/$ ls
Команда: ls
Аргументы: []

vfs:/$ cd "Мои документы"
Команда: cd
Аргументы: ['Мои документы']

vfs:/$ hello
Ошибка: неизвестная команда 'hello'.

vfs:/$ cd "незакрытая строка
Ошибка разбора: No closing quotation
```

Команда `exit` закрывает приложение.

## Структура проекта

- `src/main.py` — точка входа в программу.
- `src/gui.py` — графический интерфейс и обработка ввода.
- `src/parser.py` — разбор строки с учётом кавычек.
- `src/commands.py` — выполнение команд текущего этапа.
- `tests/` — автоматические проверки парсера и команд.
- `run.bat` — запуск на Windows.

## План дальнейшей разработки

1. REPL и заглушки команд — текущий этап.
2. Конфигурация и стартовые скрипты.
3. Виртуальная файловая система на основе ZIP в памяти.
4. Реализация `ls`, `cd`, `history`, `who`.
5. Реализация `rm` с изменениями только в памяти.
