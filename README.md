# VFS — эмулятор командной строки

Учебный проект по дисциплине «Конфигурационное управление».
Вариант №19.

Программа имитирует интерфейс командной строки UNIX-подобной
операционной системы.

## Реализованные этапы

### Этап 1. REPL

- Графический интерфейс на Tkinter.
- Разбор команд с помощью shlex.
- Поддержка аргументов в кавычках.
- Команды-заглушки ls и cd.
- Команда exit.
- Обработка неизвестных команд и ошибок ввода.

### Этап 2. Конфигурация

- Приём параметров запуска через argparse.
- Параметр --vfs для указания пути к виртуальной файловой системе.
- Параметр --script для указания стартового скрипта.
- Отображение параметров запуска в графическом интерфейсе.
- Автоматическое выполнение команд из текстового файла.
- Остановка стартового скрипта при первой ошибке.
- Тестовые BAT-файлы для Windows.
- Автоматические тесты.

## Требования

Python 3.10 или новее с поддержкой Tkinter.

Дополнительные библиотеки устанавливать не требуется.

## Запуск

Откройте папку проекта в VS Code и выполните:

```powershell
py -m src.main
```

Запуск с указанием VFS:

```powershell
py -m src.main --vfs filesystem.zip
```

Запуск со стартовым скриптом:

```powershell
py -m src.main --script startup.txt
```

Запуск с двумя параметрами:

```powershell
py -m src.main --vfs filesystem.zip --script startup.txt
```

Для просмотра доступных параметров:

```powershell
py -m src.main --help
```

На втором этапе путь к VFS только принимается и отображается.
Чтение ZIP-архива будет реализовано на третьем этапе.

## Стартовый скрипт

Стартовый скрипт — текстовый файл с командами эмулятора.

Пример содержимого startup.txt:

```text
ls
cd "Мои документы"
ls -l
```

После запуска команды выполняются автоматически.

В графическом терминале отображаются введённые команды и
результаты их выполнения.

Если возникает ошибка, выполнение скрипта прекращается.
После ошибки окно эмулятора остаётся открытым.

Команда exit завершает работу приложения.

## Поддерживаемые команды

| Команда | Описание |
| --- | --- |
| ls | Пока выводит имя команды и аргументы |
| cd | Пока выводит имя команды и аргументы |
| exit | Закрывает эмулятор |

Полноценная работа ls и cd с виртуальной файловой системой
будет реализована на четвёртом этапе.

## Структура проекта

- src/main.py — точка входа.
- src/gui.py — графический интерфейс и выполнение команд.
- src/parser.py — разбор командной строки.
- src/commands.py — обработка команд эмулятора.
- src/config.py — параметры запуска.
- src/script_runner.py — чтение стартового скрипта.
- tests/ — автоматические тесты.
- startup.txt — пример успешного стартового скрипта.
- startup_error.txt — пример скрипта с ошибкой.
- test_launch.bat — проверка вариантов запуска.
- test_errors.bat — проверка обработки ошибок.
- run.bat — стандартный запуск эмулятора.

## Автоматические тесты

Запуск всех тестов:

```powershell
py -m unittest discover -s tests -v
```

Тесты проверяют:

- Разбор команд и кавычек.
- Команды ls, cd и exit.
- Обработку неизвестных команд.
- Параметры запуска.
- Чтение стартовых скриптов.
- Остановку при первой ошибке.

## Ручное тестирование

Для Windows подготовлены два BAT-файла:

- test_launch.bat — проверяет различные параметры запуска.
- test_errors.bat — проверяет обработку ошибок.

Каждый запуск GUI необходимо завершить перед следующим тестом.
